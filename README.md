# 5-Build
Module 5 Build
The Indie Film Collective is a website designed to showcase a creative community dedicated to independent filmmakers, storytellers, and visual artists. The site provides information about the organization, workshops, film screenings, and collaborative opportunities while encouraging people to connect through independent filmmaking.
Pages include: Home, Screenings, Workshops, and Collaborations

Portions of the written content for this website were generated with the assistance of Claude and were reviewed and edited by the student. All HTML and CSS was written and created by Abigail Arevalo
The HTML is semantic and validated. 
The CSS is responsive. 
There is no Javascript.
